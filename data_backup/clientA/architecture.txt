Guide de Démarrage - Architecture Microservices

Notre plateforme utilise une architecture microservices moderne basée sur Docker et Kubernetes.

Architecture Technique:
- Frontend: React 18 avec TypeScript
- Backend: Node.js avec Express et TypeScript
- Base de données: PostgreSQL 15 pour les données transactionnelles, Redis pour le cache
- Message Queue: RabbitMQ pour la communication asynchrone
- API Gateway: Kong pour la gestion des requêtes

Déploiement:
Tous nos services sont déployés sur AWS EKS (Elastic Kubernetes Service).
Le CI/CD est géré par GitHub Actions avec des pipelines automatisés.

Monitoring:
- Prometheus pour les métriques
- Grafana pour la visualisation
- ELK Stack pour les logs
- Sentry pour le tracking des erreurs

Sécurité:
- Authentification OAuth2/OIDC
- Chiffrement TLS 1.3 pour toutes les communications
- WAF (Web Application Firewall) devant tous les endpoints publics
- Rotation automatique des secrets tous les 30 jours
